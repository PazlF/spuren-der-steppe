# Spuren der Steppe 8.2 – Museums-Spielmodus

Neu: Wahl zwischen **Kurz spielen** (Fundstück → echte Fotodetails → Forschungsspiel → Erfolg) und **Alles entdecken** (ursprüngliche ausführliche Schritte). Großflächige Spielmoduswahl, deutlicher Missionsabschluss, längerer Inaktivitätszeitraum für Museumsbesucher, Touch-/Kontrastverbesserungen.

**Hinweis:** Foto-Hotspots sind vorpositioniert, nicht kuratorisch freigegeben. Für einen Einsatz im Museum tatsächliche Tablet- und Besuchertests durchführen.

**Deployment:** gesamten entpackten Ordner inklusive `assets/photos` bei Netlify als aktualisierten Deploy hochladen. Bei alter Anzeige Browser aktualisieren; eventuell alten Service Worker/cache entfernen.
