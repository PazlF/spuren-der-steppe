# Spuren der Steppe 7.4 – Originalfoto-Redaktionsatelier

Start: `REDAKTIONSATELIER.html` im Browser öffnen. Sieben Objekte auswählen und pro Objekt das rechtmäßig bezogene Originalfoto über den Datei-Dialog importieren. Markierungen mit dem Finger verschieben; ihre Positionsangaben und überprüfte Texte als JSON bzw. CSV exportieren.

**Grenzen:** Die sieben Originalbilder sind im Paket weiterhin nicht eingebettet. Bildimport gilt nur für die aktuelle Browsersitzung; die Markertexte und Prüfhäkchen werden im lokalen Browser gespeichert. Foto und Inventarnummer sowie jede Markierung müssen am tatsächlichen Bild fachlich geprüft werden. Eine markierte Prüfung ist ein redaktionelles Häkchen, keine kuratorische Freigabe. Die Exporte aktualisieren das Hauptspiel nicht automatisch. Die Hauptanwendung ist weiterhin `index.html`.
